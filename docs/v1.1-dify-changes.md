# Dify 侧 V1.1 改动清单

> 撰于 2026-06-12 · 前端视角，Dify Workflow 开发可据此同步改造

---

## 一、新增入参（3 个）

`POST /v1/workflows/run` 请求体 `inputs` 中新增：

| 字段 | 类型 | 必填 | 说明 | 示例值 |
|------|------|------|------|--------|
| `target_audience` | string | 否 | 目标人群 | `"在职备考"` / `"宝妈备考"` / `"零基础"` / `"非科班"` / 自定义文本 |
| `theme` | string | 否 | 内容主题方向 | `"考前 30 天冲刺攻略"` / 自定义文本 |
| `include_study_material` | boolean | 否 | 是否生成学习资料卡片 | `true` / `false` |

**前端传参逻辑**：
- `target_audience`：标签选中时传标签名，自由输入有内容时传自由文本，都没选 → 空字符串 `""`
- `theme`：预设选中时传预设名，自由输入有内容时传自由文本，都没填 → 空字符串 `""`（此时前端自身会拦截，阻止生成）
- `include_study_material`：卡片序列中包含 `study_material` 类型时为 `true`，否则 `false`

## 二、新增卡片类型

`cards` 数组中新增第 9 种类型：

### `study_material` — 学习资料卡片

```json
{
  "type": "study_material",
  "title": "呼吸系统疾病 · 核心考点",
  "subtitle": "执业医师高频考点，建议收藏",
  "days": [],
  "items": [],
  "qrcode_url": "",
  "study_material": [
    {
      "module_title": "慢性阻塞性肺疾病（COPD）",
      "key_points": [
        "病因：吸烟、空气污染、职业粉尘",
        "临床表现：慢性咳嗽、咳痰、气短、呼吸困难",
        "诊断标准：FEV1/FVC < 0.7",
        "治疗原则：戒烟、支气管扩张剂、糖皮质激素"
      ],
      "memory_tips": [
        "\"吸烟咳嗽气短\" → COPD 三联征",
        "\"0.7\" → 一秒率诊断阈值"
      ],
      "source": "knowledge_base"
    },
    {
      "module_title": "支气管哮喘",
      "key_points": [
        "本质：慢性气道炎症，可逆性气流受限",
        "典型症状：发作性喘息、胸闷、咳嗽，夜间及凌晨加重",
        "治疗阶梯：按需 SABA → 低剂量 ICS → ICS+LABA"
      ],
      "memory_tips": [],
      "source": "llm_search"
    }
  ]
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `module_title` | string | 知识模块标题 |
| `key_points` | string[] | 核心考点列表，≥ 3 条 |
| `memory_tips` | string[] | 记忆方法，可为空数组 |
| `source` | `"knowledge_base"` \| `"llm_search"` | 数据来源标记 |

**生成优先级**：知识库优先 → 查不到的由 LLM Web Search 补全 → 标记 `source`。

### 前端发送的空模板

当卡片序列包含 `study_material` 时，前端向 Dify 发送的空卡片模板为：

```json
{
  "type": "study_material",
  "title": "",
  "subtitle": "",
  "days": [],
  "items": [],
  "qrcode_url": "",
  "study_material": []
}
```

## 三、现有 card type 无变化

8 种现有类型（`cover`、`plan`、`subjects`、`notice`、`cta`、`resources`、`priority`、`mnemonics`）的入参/出参结构**完全不变**。Dify Workflow 中对这些类型的 prompt 和逻辑无需修改。

## 四、Dify Workflow 改动建议

### 4.1 Prompt 模板调整

在所有卡片生成的 system prompt 中追加：

```
当前目标受众：{{target_audience}}
内容主题方向：{{theme}}

请根据目标受众的特点调整文案语气、举例方向和共鸣点：
- 在职备考：强调时间碎片化、高效利用通勤/午休时间、工作与备考平衡
- 宝妈备考：强调带娃间隙学习、碎片时间管理、家庭支持
- 零基础：强调从入门到精通、基础概念解释、循序渐进
- 非科班：强调跨专业备考策略、基础知识补全、应试技巧
```

### 4.2 学习资料卡片生成节点

当 `include_study_material == true` 时，新增一个 LLM 节点生成 `study_material` 内容：

- **输入**：`exam_name` + `target_audience` + `theme`
- **输出**：`study_material` 数组（结构见上）
- **数据来源**：先查知识库 → 无结果则 LLM Web Search → 标记 source
- **数量**：建议 2-3 个知识模块，每个 3-5 条考点

### 4.3 单卡重写 Workflow（`rewriteCard`）

前端 `rewriteCard` 目前走 mock，后续接入真实 API 时，请求体需新增：

```json
{
  "inputs": {
    "original_card": "{...}",
    "feedback": "加一些在职备考的时间管理建议",
    "target_audience": "在职备考",
    "theme": "考前 30 天冲刺攻略"
  }
}
```

## 五、前端 `services/dify.ts` 具体改动

### 5.1 `buildCardsPayload` 扩展

```ts
function buildCardsPayload(cardSequence: CardType[]) {
  return cardSequence.map(type => {
    const base = {
      type,
      title: '',
      subtitle: '',
      days: [] as PlanDay[],
      items: [] as CardItem[],
      qrcode_url: '',
    }
    // ★ 新增：study_material 类型附加空数组
    if (type === 'study_material') {
      return { ...base, study_material: [] }
    }
    return base
  })
}
```

### 5.2 `generateCards` 入参扩展

```ts
export async function generateCards(
  params: DifyGenerateParams & {
    targetAudience?: string
    theme?: string
    includeStudyMaterial?: boolean
  },
  onProgress?: ProgressCallback,
): Promise<DifyGenerateResult> {
  // ...
  body: JSON.stringify({
    inputs: {
      exam_name: examName,
      exam_date: examDate,
      cards: JSON.stringify(cardsPayload),
      role: role,
      countdown_days: timeVars.countdownDays,
      phase_1_end: timeVars.phase1End,
      phase_2_end: timeVars.phase2End,
      today_date: timeVars.today,
      // ★ 新增
      target_audience: params.targetAudience ?? '',
      theme: params.theme ?? '',
      include_study_material: params.includeStudyMaterial ?? false,
    },
    response_mode: 'streaming',
    user: 'workbench-user',
  }),
}
```

### 5.3 `parseSSEStream` 无需改动

出参解析逻辑不变 — `study_material` 卡片和其他卡片一样，都在 `event.data.outputs.cards` 数组中返回。前端按 `type` 字段分发渲染。

## 六、汇总

| 维度 | 改动 |
|------|------|
| Dify Workflow 入参 | +3 个字段（`target_audience`, `theme`, `include_study_material`） |
| Dify Workflow 出参 | cards 数组新增 `study_material` 类型（含 `module_title`, `key_points`, `memory_tips`, `source`） |
| Dify Workflow 逻辑 | 新增学习资料卡片生成节点；所有 prompt 追加人群+主题上下文 |
| 前端 `services/dify.ts` | `buildCardsPayload` 适配新 type；`generateCards` 传 3 个新入参；`parseSSEStream` 不改 |
| 前端类型 | `CardType` 加 `'study_material'`；`DifyGenerateParams` 加 3 个字段 |
