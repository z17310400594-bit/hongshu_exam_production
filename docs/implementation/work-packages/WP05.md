# WP05：知识点及资料映射（MVP）

- 依赖：WP03、WP04
- MVP 停止点：`feat: add reusable knowledge graph`
- MVP 裁剪：保留后续 WP06/WP08/WP09/WP10 需要的知识点、关系、范围和片段映射骨架；暂不做完整知识图谱遍历、批量导入、合并工作流 UI、黄金集评测。

## 范围说明

从 `C:\Users\ADMINI~1\AppData\Local\Temp\codex_handoff_mvp_wp05.md` 开始，WP05+ 切换为 MVP 节奏：先打通 `asset/version/fragment -> knowledge point -> approved reference -> API query`，不把每个工作包都拉回生产级验收强度。

本包仍保留关键安全底线：

- 空库可通过 Alembic migration 建表；
- ORM registry、Alembic check、metadata diff 不允许假绿；
- 片段查询必须经过集合 ACL；
- `pending/rejected` 映射不进入高可信查询；
- 合并/弃用保留历史 `code`，不直接删除知识点。
