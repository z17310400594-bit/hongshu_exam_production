## MVP 不做项

- 不实现真正的长任务队列和完整 SSE；`POST /api/v2/generations` 同步返回草稿结果，后续可平滑替换为异步。
- 不实现审核大后台；只在当前图文生成页展示引用并阻止无引用结果通过。
- 不把 Dify key 放回前端；后端可通过环境变量配置 Dify，未配置时使用本地可测试草稿生成器。
