## MVP 不做项

- 不切换真实生产 feature flag 或 API 流量。
- 不执行真实备份恢复、对象存储恢复或旧库权限变更。
- 不归档或删除旧库；本包只校验“旧库只读保留至少两个发布周期”的计划。
