## MVP 不做项

- 不接生产旧 API 实时双读流量；runner 先支持 JSONL 固化样本，后续可接 URL 采集。
- 不要求本包补齐 100 条真实黄金问题；只提供 sample JSONL 和可重复跑的评分逻辑。
- 不做生产量级压测；保留 CLI/报告入口，实际压测需真实数据和机器资源后另跑。
