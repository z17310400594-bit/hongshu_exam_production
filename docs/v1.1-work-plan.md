## 一、V1 基线快照

现有代码已实现 V1 全部功能，核心架构如下：

| 层 | 文件 | 职责 |
|---|---|---|
| 页面入口 | `pages/workbench/index.tsx` | page-view 切换容器 |
| 内容生产组件 | `pages/workbench/components/ExamArticle/index.tsx` | 910 行，左栏输入 + 右栏预览 + Dialog |
| Store | `store/examArticleStore.ts` | 288 行，Zustand，含生成/审核/编辑/重写/版本切换 |
| 类型 | `types/exam-article.ts` | CardType 联合类型（8 种）、CardData、GeneratedContent 等 |
| 卡片模板常量 | `constants/card-templates.ts` | 4 个预设序列（STANDARD/COMPACT/PLAN_TYPE/KNOWLEDGE_TYPE） |
| 考试类目 | `constants/exam-categories.ts` | 5 个考试预设（医师/护士/教资/注安/消防） |
| 风格 Token | `constants/style-tokens.ts` | 3 套风格（医考蓝/学霸粉/极简灰） |
| Dify 服务 | `services/dify.ts` | generateCards + rewriteCard + reviseByFeedback |
| 工具函数 | `utils/validation.ts` | getCardPlainText / deepClone / validateGeneratedContent |

**现有 CardType（8 种）**：`cover | plan | subjects | notice | cta | resources | priority | mnemonics`

**现有预设组合（4 个按钮）**：6 张标准 / 5 张精简 / 计划型 / 知识型

**确认 Dialog 现有字段**：考试名、考试日期、倒计时、卡片数量、卡片序列、风格

### 2.6 组件层（`ExamArticle/index.tsx`）— **改动最大**

#### 2.6.1 左栏输入区新增

在「考试日期」下方、「卡片编排」上方，新增两个 form-group：

**目标人群区**（AC-16, AC-17）：
```
目标人群
[在职备考] [宝妈备考] [零基础] [非科班]     ← 4 个标签 chip，选中高亮，单选
或自定义输入：[________________]              ← 与标签互斥
```

**主题区**（AC-18, AC-19）：
```
主题方向
预设：[考前 30 天冲刺攻略 ▾]（可选）         ← 下拉选择，选中后输入框禁用
或自由输入：[________________]               ← 自由文本
```

校验逻辑：
- 未选预设也未填主题 → 点击生成时标红提示「请选择或输入主题」（AC-19）
- 目标人群选了自由输入但为空 → 确认 Dialog 里标黄提示（AC-20）

#### 2.6.2 卡片编排区

- 「含备考资料」7 张预设按钮追加到预设按钮行（AC-6 回归）

#### 2.6.3 确认 Dialog（AC-20）

新增两行：
```
目标人群：在职备考（或「（自定义）xxx」/ 「（未填写）⚠️」）

```

#### 2.6.4 卡片预览区（renderCardPreview）

新增 `case 'study_material'` 分支：
```tsx
case 'study_material':
  bodyHtml = (
    <View>
      <Text className='card-title'>{displayCard.title}</Text>
      <Text className='card-subtitle'>{displayCard.subtitle}</Text>
      <View className='card-divider' />
      {(displayCard.study_material ?? []).map((mod, mi) => (
        <View key={mi} className='study-module'>
          <Text className='module-title'>📚 {mod.module_title}</Text>
          <View className='key-points'>
            {(mod.key_points ?? []).map((kp, ki) => (
              <Text key={ki} className='key-point'>• {kp}</Text>
            ))}
          </View>
          {mod.memory_tips && mod.memory_tips.length > 0 && (
            <View className='memory-tips'>
              <Text className='tips-label'>💡 记忆方法：</Text>
              {(mod.memory_tips ?? []).map((tip, ti) => (
                <Text key={ti} className='tip-item'>{tip}</Text>
              ))}
            </View>
          )}
          {mod.source && (
            <Text className='source-tag'>来源：{mod.source === 'knowledge_base' ? '知识库' : 'LLM 搜索'}</Text>
          )}
        </View>
      ))}
    </View>
  )
  break
```

## 五、风险与备注

1. **Dify Workflow 侧**：`target_audience`、`theme`、`include_study_material` 三个新入参 + `study_material` 出参需要 Dify 侧同步改造。前端可以先传参，Dify 未适配时只影响生成内容质量，不会报错。
2. **单卡重写**：`rewriteCard` 目前走 mock 逻辑，需同步传递新参数。
3. **html2canvas 导出**：新增卡片类型理论上自动兼容（导出时截图 DOM），但 study_material 内容较长时需要确认 3:4 比例下不会溢出。
4. **UI 可能后续调整**：PRD 中提到 V1.1 原型已交付，UI 细节以原型为准，本次以功能正确性为优先。
