## 二、切分总参数

| 参数 | 值 | 理由 |
|------|---|------|
| **chunk_size** | 800 tokens（≈ 500-700 中文字符） | 匹配一个完整知识点的自然粒度 |
| **chunk_overlap** | 60 tokens（≈ 40-60 中文字符） | 保留上下文衔接，不切断跨页内容 |
| **separator** | `\n(?=第[一二三四五六七八九十]+[章节])` `\n(?=[一二三四五六七八九十]+[、．.])` | 在章/节/知识点编号处断开 |
| **检索模式** | 混合检索（向量 0.7 + 关键词 0.3） | 保证专业术语（药品名、法规编号）能被精确命中 |
| **Top-K** | 5 | |
| **Score 阈值** | 0.5（建议先不启用，上线后再调） | 初期不设阈值保证召回，后续根据效果收紧 |

### 3.2 切分规则

**主规则：一个药物 = 一个 chunk**

每味药自成 chunk，内容包含：药名 + 性能特点 + 功效 + 主治 + 所属章节。

**辅规则：章节头信息（定义/分类/使用注意）+ 配伍使用 = 独立 chunk**

章节开头的「一、定义」「二、分类」「三、使用注意」以及末尾的「配伍使用」单独成 chunk，不跟第一个/最后一个药物合并。

### 4.2 切分规则

**主规则：一个编号知识点 = 一个 chunk**

以「一、」「二、」「（一）」「（二）」等编号为边界切分。包含标题 + 表格 + 后续解释段落。

**辅规则：表格过长时，表内每个一级行 + 其二级内容 = 独立子 chunk**

如「健康中国战略概要」表格含 8 个一级行，每行（战略主题/核心/原则/战略目标...）各自成 chunk，但保持章节溯源。

**特殊处理：**
- 页码、页眉（如"执业药师与公众健康"章节名重复出现）→ 删除
- PDF 提取导致的跨页断裂 → 用 overlap 补回
- 化学结构图/公式（西药一中常见）→ 保留文本描述 + 标记 [化学结构见原文]

## 六、预处理脚本逻辑

```python
# 伪代码：PDF → Dify-ready chunks

def preprocess_pdf(pdf_path, book_type):
    """
    book_type: 'A' (条目表格式) | 'B' (知识点叙述式)
    """
    text = extract_text_from_pdf(pdf_path)
    text = clean_pdf_artifacts(text)  # 去页码/页眉/乱码

    # 按章切分
    chapters = split_by_chapter(text)

    chunks = []
    for ch in chapters:
        if book_type == 'A':
            # 中药二模式：按药物条目切分
            sections = split_by_section(ch)
            for sec in sections:
                # 先提取章节头信息 → chapter_overview chunk
                overview = extract_overview(sec)
                if overview:
                    chunks.append(make_chunk(overview, 'chapter_overview'))

                # 再按药物逐条切分
                drugs = extract_drug_entries(sec)
                for drug in drugs:
                    chunks.append(make_chunk(drug, 'drug_entry'))

                # 配伍使用 → drug_pair chunk
                pairs = extract_drug_pairs(sec)
                for pair in pairs:
                    chunks.append(make_chunk(pair, 'drug_pair'))

        elif book_type == 'B':
            # 法规/西药模式：按编号知识点切分
            sections = split_by_numbered_items(ch)
            for sec in sections:
                if len(sec) > 800:  # 超长知识点二次切分
                    sub_items = split_by_table_rows(sec)
                    for sub in sub_items:
                        chunks.append(make_chunk(sub, 'key_point'))
                else:
                    chunks.append(make_chunk(sec, 'key_point'))

    return chunks
```

## 九、实施步骤

1. **PDF 文本提取** — 用 pymupdf 提取 7 本书全文（~30 分钟脚本运行）
2. **清洗** — 去页码、去页眉、修复跨页断裂、去乱码
3. **自动切分** — 按上述规则，A 类按药物切，B 类按编号切
4. **Metadata 注入** — 自动生成 chapter/section/topic/page 等字段
5. **人工抽检** — 每本书抽 20 个 chunk 检查切分质量
6. **上传 Dify** — 批量导入，创建知识库「执业药师-考点库」
7. **检索测试** — 用高频查询（麻黄/健康中国/半衰期/ADR…）验证召回
