# 卡片生成 Workflow — 数据库注入方案（v2）

> 生产 Workflow: START → CODE_1 → Iterator(CODE_A → LLM) → CODE_2 → END  
> 目标: 前端的 `exam_name` 命中数据库 → 注入真实数据；未命中 → LLM 自由发挥

---

## 一、核心设计：exam_name 查找 → 命中/未命中分流

### 1.1 为什么不是 cert_id

当前前端传给 Workflow 的是 `exam_name`（如 "执业医师资格证"），不是 `cert_id`（如 `physician_licensed`）。前端还支持手动输入考试类型，手动输入大概率不在预设列表里。

如果直接让前端传 `cert_id`:
- 需要前端维护一份 cert_id 映射表 → 耦合
- 手动输入的考试没有 cert_id → 又要加 fallback → 逻辑复杂
- 以后加新考试类型 → 前端也要改

### 1.2 exam_name → cert_id 查找

```
前端 exam_name ──→ CODE_0_db ──→ POST /query/cert_lookup ──→ cert_basic 表
       │                │
       │                ├── 命中 → cert_id → 调 policy/knowledge/viral → 注入
       │                │
       │                └── 未命中 → db_data_json = "{}" → LLM 自由生成
```

**匹配策略（三级降级）**：

| 优先级 | 匹配方式 | 示例 |
|--------|---------|------|
| 1 | `exam_name` 完全等于 `cert_name` | "医师资格证" = "医师资格证" → ✅ |
| 2 | `exam_name` 包含在 `cert_name` 中，或反过来 | "执业医师资格证" 包含 "医师资格证" → ✅ |
| 3 | 都不命中 | "注册安全工程师" → ❌ → LLM |

### 1.3 长期设计：前端预设从数据库来

```
┌─────────────┐     GET /query/certs      ┌──────────────┐
│  前端下拉框   │ ◄────────────────────── │  policy-api   │
│  (Taro App)  │     返回所有证书列表       │  :8400        │
└──────┬──────┘                           └──────┬───────┘
       │                                         │
       │ 用户选择 → exam_name = "医师资格证"       │ cert_basic 表
       │ 用户手动 → exam_name = "注册岩土工程师"   │ 3 条记录
       │                                         │
       ▼                                         │
  Dify Workflow ──→ CODE_0_db ──→ cert_lookup ──┘
```

**好处**：
- 前端下拉选项 = 数据库实时查询 → 永远和数据库一致
- 下拉选的 `exam_name` 一定命中 → 必然走 DB 注入
- 手动输入的 → 走查找，命中就注入，不命中就 LLM
- 加新考试类型 = 往数据库里插一条 cert_basic → 前端自动出现

## 三、policy-api 新增接口

### 3.1 `POST /query/cert_lookup` — 考试名查找

```
输入: {"exam_name": "执业医师资格证"}
输出: {"matched": true, "cert_id": "physician_licensed", "cert_name": "医师资格证", "short_name": "医师"}
  或: {"matched": false, "cert_id": "", "cert_name": "", "short_name": ""}
```

**查找逻辑**（三级降序）：

```python
def _cert_lookup(conn, exam_name: str) -> dict | None:
    """三级匹配：精确 → 包含 → 未命中"""
    # 1. 精确匹配
    rows = _query(conn,
        "SELECT cert_id, cert_name, short_name FROM cert_basic WHERE cert_name = %s",
        (exam_name,))
    if rows: return rows[0]

    # 2. 包含匹配（双向）
    rows = _query(conn,
        "SELECT cert_id, cert_name, short_name FROM cert_basic "
        "WHERE %s LIKE '%' || cert_name || '%' OR cert_name LIKE '%' || %s || '%' "
        "LIMIT 1",
        (exam_name, exam_name))
    if rows: return rows[0]

    # 3. 未命中
    return None
```

### 3.2 `GET /query/certs` — 证书列表（供前端下拉框）

```
输出: {"certs": [
  {"cert_id": "physician_licensed", "cert_name": "医师资格证", "short_name": "医师"},
  {"cert_id": "pharmacist_licensed", "cert_name": "药师资格证", "short_name": "药师"},
  {"cert_id": "nle", "cert_name": "护士执业资格证", "short_name": "护士"},
], "count": 3}
```

前端调用此接口 → 填充下拉框 → 用户选的 `exam_name` 一定来自数据库 → 命中率 100%。

## 四、新增节点 CODE_0_db

### 4.1 位置

START 之后、CODE_1 之前。

### 4.2 输入

| 变量 | 来源 | 说明 |
|------|------|------|
| `exam_name` | `{{START.exam_name}}` | 复用现有变量，不加新的 |

### 4.3 输出

| 变量 | 说明 |
|------|------|
| `db_data_json` | 命中 → 完整 JSON；未命中 → `"{}"` |
| `db_matched` | `"true"` / `"false"`，供后续节点判断 |
| `resolved_cert_id` | 解析后的 cert_id（未命中为空串） |

### 4.4 代码

```python
import json
import urllib.request
import urllib.error

API_BASE = "http://policy-api:8400"


def _api_post(endpoint, data):
    try:
        body = json.dumps(data).encode("utf-8")
        req = urllib.request.Request(
            f"{API_BASE}{endpoint}",
            data=body,
            headers={"Content-Type": "application/json"},
            method="POST",
        )
        with urllib.request.urlopen(req, timeout=15) as resp:
            return json.loads(resp.read().decode("utf-8"))
    except Exception:
        return {}


def _api_get(endpoint):
    try:
        req = urllib.request.Request(
            f"{API_BASE}{endpoint}",
            headers={"Content-Type": "application/json"},
            method="GET",
        )
        with urllib.request.urlopen(req, timeout=10) as resp:
            return json.loads(resp.read().decode("utf-8"))
    except Exception:
        return {}


def main(exam_name: str = "") -> dict:
    # 空输入直接降级
    if not exam_name or not exam_name.strip():
        return {
            "db_data_json": "{}",
            "db_matched": "false",
            "resolved_cert_id": "",
        }

    # 1. 查找 cert_id
    lookup = _api_post("/query/cert_lookup", {"exam_name": exam_name.strip()})

    if not lookup.get("matched"):
        return {
            "db_data_json": "{}",
            "db_matched": "false",
            "resolved_cert_id": "",
        }

    cert_id = lookup["cert_id"]

    # 2. 查询全量数据
    policy = _api_post("/query/policy", {"cert_id": cert_id})
    knowledge = _api_post("/query/knowledge", {"cert_id": cert_id})
    viral = _api_post("/query/viral", {"cert_id": cert_id, "limit": 5})

    # 3. 组装
    db_data = {
        "cert_name": policy.get("cert_name", exam_name),
        "short_name": policy.get("short_name", ""),
        "issuing_authority": policy.get("issuing_authority", ""),
        # 科目（满分 + 题型）
        "subjects": knowledge.get("subjects", []),
        # 知识点（含频次）
        "knowledge_points": knowledge.get("knowledge_points", []),
        # 考试安排（最新一条）
        "schedule": (
            policy.get("exam_schedules", [None])[0]
            if policy.get("exam_schedules")
            else None
        ),
        # 合格标准
        "score_rules": policy.get("score_rules", []),
        # 政策条款
        "policy_clauses": policy.get("policy_clauses", []),
        # 爆款标签
        "viral_tags": [],
    }

    # 提取爆款标签
    for v in viral.get("samples", []):
        tags = v.get("tags", [])
        if isinstance(tags, list):
            db_data["viral_tags"].extend(tags)
    db_data["viral_tags"] = list(set(db_data["viral_tags"]))[:10]

    return {
        "db_data_json": json.dumps(db_data, ensure_ascii=False),
        "db_matched": "true",
        "resolved_cert_id": cert_id,
    }
```

## 五、数据库能喂给 9 种卡片什么

| 卡片类型 | 数据库给什么 | 来源表 | 怎么注入 |
|----------|-------------|--------|---------|
| **study_material** | 知识点名 + 频次 + 解析 | `knowledge_point` | CODE_1 按 assigned_chapter 匹配 |
| **subjects** | 真实科目名 + 满分 + 题型 | `exam_subject` | 全部注入，LLM 排序 |
| **priority** | 科目分值 + 知识点频次统计 | `exam_subject` + `knowledge_point` | 注入统计，LLM 生成策略 |
| **mnemonics** | 高频考点作口诀锚点 | `knowledge_point` (frequency=高频) | 取 3-5 个 |
| **notice** | 报名/考试/出分日期 | `exam_schedule` | 注入最新一条 |
| **plan** | 考试日期 | — | START 已有，不需要 |
| **cover** | cert_name | `cert_basic` | 代替 LLM 记忆 |
| **resources** | 科目名 + 考点名 | `exam_subject` + `knowledge_point` | 注入作资料名 |
| **cta** | — | — | 不需要 |

## 六、CODE_1 改动（接收 db_data_json 并注入）

### 6.1 新增输入变量

```
db_data_json: str  ← {{②.db_data_json}}
```

### 6.2 新增注入逻辑（在 `# ── 7. 为每张卡片注入上下文` 之后）

```python
# ── 8. 注入数据库数据 ──
db_data = {}
if db_data_json and db_data_json != "{}":
    try:
        db_data = json.loads(db_data_json)
    except json.JSONDecodeError:
        pass

if db_data:
    kps = db_data.get("knowledge_points", [])
    subjects = db_data.get("subjects", [])
    schedule = db_data.get("schedule")
    cert_name = db_data.get("cert_name", "")

    for i, item in enumerate(enriched):
        card_type = item.get("type", "")

        # 所有卡片注入 cert_name
        if cert_name:
            item["db_cert_name"] = cert_name

        if card_type == "study_material":
            # 按 assigned_chapter 匹配知识点
            chapter = item.get("assigned_chapter", "")
            if chapter and kps:
                matched = [k for k in kps if chapter in k.get("kp_name", "")]
                if not matched:
                    matched = kps[:3]  # 没匹配到就给前 3 个
                item["kp_data"] = matched
            elif kps:
                item["kp_data"] = kps[:5]

        elif card_type == "subjects":
            if subjects:
                item["subjects_data"] = subjects

        elif card_type == "priority":
            if subjects and kps:
                kp_by_subject = {}
                for k in kps:
                    s = k.get("subject_name", "未知")
                    kp_by_subject[s] = kp_by_subject.get(s, 0) + 1
                item["priority_data"] = {
                    "subjects": subjects,
                    "kp_counts": kp_by_subject,
                }

        elif card_type == "mnemonics":
            high_kps = [k for k in kps if k.get("frequency") == "高频"]
            item["mnemonic_anchors"] = high_kps[:5] if high_kps else kps[:5]

        elif card_type == "notice":
            if schedule:
                item["schedule_data"] = {
                    "exam_date": schedule.get("exam_date", ""),
                    "registration_start": schedule.get("registration_start", ""),
                    "registration_end": schedule.get("registration_end", ""),
                    "result_date": schedule.get("result_date", ""),
                    "year": schedule.get("year", ""),
                }
```

### 6.3 风险控制

| 场景 | 行为 |
|------|------|
| `exam_name` = "执业医师资格证" | 命中 DB → 注入真实考点/科目/日期 |
| `exam_name` = "注册安全工程师"（DB 无） | 查找失败 → `db_data_json = "{}"` → 走旧逻辑 |
| `exam_name` = "" (空) | CODE_0_db 直接返回空 → 走旧逻辑 |
| policy-api 挂了 | `_api_post` 返回 `{}` → 降级 |
| DB 里只有 3 条 cert | 只命中这 3 个，其余全部走 LLM |

**完全向后兼容，零风险。**

## 七、CODE_A 改动

### 7.1 study_material（知识库模式增强）

当 `card.kp_data` 存在时，在 User Prompt 里追加：

```
## 教材知识点（来自数据库——以下内容必须覆盖）

{% for kp in card.kp_data %}
- [{kp.frequency}] {kp.kp_name}
  {% if kp.note %}说明：{kp.note}{% endif %}
{% endfor %}

请将以上知识点用口语翻译成"学姐讲考点"的风格。
数值和定义必须准确，但表达方式用微信聊天的语气。
```

### 7.2 subjects（科目卡增强）

当 `card.subjects_data` 存在，追加：

```
## 真实考试科目（来自数据库）

{% for s in card.subjects_data %}
- {s.subject_name}（满分 {s.full_mark} 分，题型：{s.question_types}）
{% endfor %}

请基于以上真实科目生成策略，不要凭记忆编造科目名。
```

### 7.3 priority（分值分布增强）

类似 subjects。

### 7.4 mnemonics（口诀增强）

当 `card.mnemonic_anchors` 存在：

```
## 需要编口诀的考点（来自数据库）

{% for kp in card.mnemonic_anchors %}
- {kp.kp_name}
{% endfor %}

请为以上考点各编一条记忆口诀。
```

## 十一、数据库现状

当前 `policy_fact` 已录入 3 个证书：

| cert_id | cert_name | 知识点 | 科目 | 真题 | 政策条款 |
|---------|-----------|--------|------|------|---------|
| `physician_licensed` | 医师资格证 | 12 | 5 | 10 | 2 |
| `pharmacist_licensed` | 药师资格证 | 待查 | 待查 | 待查 | 待查 |
| `nle` | 护士执业资格证 | 待查 | 待查 | 待查 | 待查 |

前端传 `exam_name` = "医师资格证" / "执业医师资格证" / "医师" → 命中 `physician_licensed`。
