# 考试日程 — 数据结构与录入说明

> 共享库：前端考试下拉 + Dify notice 卡片 都用这一份。
> 维护频率：每年每个证书一行，往年数据保留（能答"去年什么时候考"）。

## 连接信息
- 表名：`exam_schedule`（库 `policy_fact`，容器 `policy-db`）
- CSV 模板：`CSV模板/exam_schedule.csv`
- 导入命令：见 §三

---

## 一、表结构

```sql
exam_schedule
├─ schedule_id         VARCHAR(32) PK     -- 命名规则 sched_{cert_id}_{year}
├─ cert_id             VARCHAR(32) FK     -- → cert_basic.cert_id
├─ year                INTEGER NOT NULL   -- 年份
├─ registration_start  DATE               -- 报名开始
├─ registration_end    DATE               -- 报名截止
├─ exam_date           DATE               -- 考试日期（多天取首日）
├─ result_date         DATE               -- 成绩公布日
├─ region_note         TEXT               -- 各省差异、多阶段说明
└─ created_at          TIMESTAMPTZ        -- 自动填
```

索引：`(cert_id, year)` 联合索引，查"某证书某年"走索引。

## 二、与业务的关系

### 2.1 前端考试下拉

`GET /query/certs` 目前不返回考试日期。计划后续 JOIN `exam_schedule` 按当前年份取最近一场：

```sql
SELECT cb.*, es.exam_date, es.registration_start, es.registration_end
FROM cert_basic cb
LEFT JOIN exam_schedule es ON cb.cert_id = es.cert_id AND es.year = 2026
ORDER BY cb.cert_id;
```

API 加字段后，前端下拉可以直接展示"执业药师（10.18考试）"。

### 2.2 Dify notice 卡片

CODE_1 已支持 `schedule_data` 注入：

```python
# CODE_1 → notice 卡片
item["schedule_data"] = {
    "exam_date": schedule.get("exam_date", ""),
    "registration_start": schedule.get("registration_start", ""),
    "registration_end": schedule.get("registration_end", ""),
    "result_date": schedule.get("result_date", ""),
    "year": schedule.get("year", ""),
}
```

CODE_A 的 notice 卡片 system_prompt 会基于这些数据生成考前须知内容。

### 2.3 Dify CODE_0_db

CODE_0_db 按 cert_id + 最近年份查 schedule：

```python
# 伪代码

    SELECT * FROM exam_schedule

```

## 三、录入方式

### 方式 A：CSV 批量导入（推荐）

模板位置：`CSV模板/exam_schedule.csv`

每行一个证书×一年。日期填 `YYYY-MM-DD`，不确定的字段留空（两个逗号之间不写东西）。

```bash
docker exec -i policy-db psql -U policy -d policy_fact -c \
"\copy exam_schedule(schedule_id,cert_id,year,registration_start,registration_end,exam_date,result_date,region_note) \
FROM '/dev/stdin' WITH (FORMAT csv, HEADER true)" < exam_schedule.csv
```

### 方式 B：SQL INSERT

```sql
INSERT INTO exam_schedule (schedule_id, cert_id, year, registration_start, registration_end, exam_date, result_date, region_note)
VALUES ('sched_pharmacist_2026', 'pharmacist_licensed', 2026, '2026-06-16', '2026-07-05', '2026-10-17', NULL, '10月17-18日考试;各地报名时间略有不同');
```

### CSV 模板列说明

| 列名 | 示例 | 说明 |
|------|------|------|
| schedule_id | `sched_physician_2026` | 主键，模式：`sched_{cert_id}_{year}` |
| cert_id | `physician_licensed` | 必须已在 cert_basic 中存在 |
| year | `2026` | 整数 |
| registration_start | `2026-02-08` | 精确到日 |
| registration_end | `2026-02-21` | 精确到日 |
| exam_date | `2026-06-14` | 多天/多阶段取第一天，备注写 region_note |
| result_date | `2026-09-01` | 可留空 |
| region_note | `实践技能6月14-25日;医学综合8月22-24日` | 自由文本，分号分隔多条说明 |

## 五、维护节奏

1. **每年 Q1**：当年考试安排陆续公布，录新一年的行
2. **出成绩后**：补 `result_date`
3. **不删历史行**：保留往年数据用于查询"去年什么时候考的"
4. **cert_basic 新增证书时**：同步在 exam_schedule 里加对应行

## 六、校验

```sql
-- 1. 引用了不存在的证书（孤儿日程）
SELECT schedule_id, cert_id FROM exam_schedule
WHERE cert_id NOT IN (SELECT cert_id FROM cert_basic);

-- 2. 同一年同一证书重复
SELECT cert_id, year, count(*) FROM exam_schedule
GROUP BY cert_id, year HAVING count(*) > 1;

-- 3. 缺少 2026 日程的证书
SELECT cert_id, cert_name FROM cert_basic
WHERE cert_id NOT IN (
  SELECT cert_id FROM exam_schedule WHERE year = 2026
);
```
