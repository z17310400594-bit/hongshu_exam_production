 四、导入后校验 SQL（在 psql 里跑）
================================================================

进入数据库：
  docker exec -it policy-db psql -U policy -d policy_fact

然后逐个执行：

-- 1. 报考条件漏挂条款
SELECT condition_id, cert_id FROM exam_condition WHERE source_clause_id IS NULL;

-- 2. 孤儿条款
SELECT c.clause_id FROM policy_clause c
LEFT JOIN policy_doc d ON c.doc_id=d.doc_id WHERE d.doc_id IS NULL;

-- 3. 引用废止政策
SELECT c.clause_id, d.effective_status FROM policy_clause c
JOIN policy_doc d ON c.doc_id=d.doc_id WHERE d.effective_status='废止';

-- 4. 没挂考点的题目
SELECT question_id, exam_year FROM exam_question q
WHERE NOT EXISTS (SELECT 1 FROM exam_question_kp r WHERE r.question_id=q.question_id);

-- 5. 考点实际命中频次（修正 frequency 用）
SELECT k.kp_name, k.frequency AS 标记, count(r.question_id) AS 实际题数
FROM knowledge_point k
LEFT JOIN exam_question_kp r ON k.kp_id=r.kp_id
GROUP BY k.kp_name, k.frequency
ORDER BY 实际题数 DESC;

-- 6. 孤儿关联（复核）
SELECT * FROM exam_question_kp r
LEFT JOIN exam_question q ON r.question_id=q.question_id
WHERE q.question_id IS NULL;


================================================================
 五、注意事项
================================================================

1. CSV 必须是 UTF-8 编码（Excel 编辑后默认 GBK，导入前另存为 UTF-8）
2. JSONB 字段（tags、options）里双引号写成 "" 转义
3. 日期格式：YYYY-MM-DD（如 2025-03-10）
4. 布尔值：true / false（小写）
5. 空值：直接留空（两个逗号之间什么都不写），不要写 NULL 或 ""
